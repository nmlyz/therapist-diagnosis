therapist-diagnosis writes one line to a text file: the diagnosis an AI therapist hands its human after a session. The line was picked from 44 candidates by pairwise judging against the brief — the therapist is the subject, the turn lands on the last word, and the voice never breaks its flat clinical calm. The therapist does not raise its voice; it just reads the chart and lets the patient hear it.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 89 characters, a single line, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
